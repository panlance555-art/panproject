About the Machine Learning Model

Learn how the SMS Spam Detection System works.

Project Overview

This system uses Natural Language Processing (NLP) and Machine Learning to classify SMS messages as HAM (legitimate) or SPAM.


Dataset Information

Dataset: UCI SMS Spam Collection

Original messages: 5,572

Cleaned messages: 5,169

Training records: 4,135

Testing records: 1,034


Text Processing

The system uses TF-IDF (Term Frequency-Inverse Document Frequency) to convert text messages into numerical features that machine learning algorithms can process.

The text processing uses lowercase conversion, English stop-word removal, and unigram and bigram features.


Algorithms Tested

  • Multinomial Naive Bayes: A probability-based algorithm used for text classification.
  • Logistic Regression: A classification algorithm used to predict message categories.
  • Linear Support Vector Machine (SVM): A classification algorithm that finds a decision boundary between HAM and SPAM messages.

Model Performance Comparison

Algorithm Accuracy Precision Recall F1-Score
Naive Bayes 95.36% 100.00% 63.36% 77.57%
Logistic Regression 94.58% 97.47% 58.78% 73.33%
Linear SVM 97.87% 95.80% 87.02% 91.20%

Selected Model: Linear SVM

Linear SVM was selected because it achieved the highest spam F1-score of 91.20% among the three tested algorithms.

Its test results include 898 correctly classified HAM messages, 114 correctly classified SPAM messages, 5 HAM messages incorrectly classified as SPAM, and 17 SPAM messages incorrectly classified as HAM.


How the System Works

  1. The user enters an SMS message.
  2. The system receives the message.
  3. TF-IDF converts the text into numerical features.
  4. The trained Linear SVM model classifies the message.
  5. The system displays HAM or SPAM.
  6. The detection result is saved in the history database.
